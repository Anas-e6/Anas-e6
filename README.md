## 🚀 Proyecto destacado

### 🏥 [Hospital Montserrat — Projecte intermodular](https://github.com/Anas-e6/hospital-montserrat)
Sistema de gestión hospitalaria hecho con **Jose Arranz** ([@jarranz-boop](https://github.com/jarranz-boop)) en el proyecto intermodular de ASIX:

- **PostgreSQL** con procedimientos, funciones y triggers en PL/pgSQL (16 tablas).
- **Seguridad**: 8 roles con privilegios mínimos, contraseñas con bcrypt, SSL y documentación RGPD.
- **Alta disponibilidad**: replicación servidor principal → esclavo y copias de seguridad automatizadas.
- **Aplicación de escritorio** en Python (Tkinter + psycopg2) y **dashboard en Power BI**.
